# LD Line — site estático

Site institucional servido no GitHub Pages.

## Páginas

- `index.html` — Home (`/`)
- `quem-somos/index.html` — Quem somos
- `tratamentos/index.html` — Tratamentos
- `contato/index.html` — Contato
- `404.html` — página não encontrada

## Testar localmente

```powershell
npx --yes serve .
```

## Notas

- `CNAME` define o domínio. Não apagar.
- `.nojekyll` mantém o comportamento estático. Não apagar.
